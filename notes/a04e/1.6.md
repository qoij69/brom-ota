# BROM 1.6 — Galaxy A04e

The updater now downloads, installs and cleans up on its own.

## What's new

- Progress fills the update button while the package downloads
- Reopening Software update picks the download back up where it left off
- Updates download silently, without a notification in the shade
- "Install now" reboots into recovery, flashes, and boots back automatically
- The update package is removed from Download once the flash succeeds

## Bugs that have been fixed

- Progress no longer overlaps the changelog text
- Percentage and remaining time no longer overlap each other
- An already-finished download is detected instead of restarting
- A04e updates no longer mix in A04 files or the other way round
