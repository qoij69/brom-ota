# BROM 1.5 — Galaxy A04e

Boot and stability update for the Galaxy A04e.

## Bugs that have been fixed

- Fixed the A04e first boot hang caused by vendor SELinux policy
- Fixed the A04e SystemUI crash and missing navigation bar
- Fixed signature mismatch on the A04e system apps
- Fixed blank app previews in Recents
- Fixed video recording in the stock Samsung camera

## What's new

- Software update in Settings now opens the BROM updater
- Update checks, changelogs and downloads inside the updater
- A04e system apps re-signed with the BROM key
